# Just another ruler, but better.

A ruler that stays on your screen, in real centimeters, and gets out of the way when you are not using it.

Measure a window, a card on the desk, a gap in a layout. Nothing to print. No guessing in pixels.

## Built to measure, not to get in the way

It opens in the center, above whatever you are looking at. A click outside the ruler goes straight through to the app behind it. Drag it, turn it, and keep working.

The scale uses the physical size of the monitor. One centimeter on the ruler is one centimeter on the screen.

## What you can do

- **Move** it anywhere on the screen.
- **Rotate** it in any direction, with a light snap every 45°.
- **Stretch** it when the distance does not fit.
- **Read centimeters**, with millimeters when the screen can show them.
- **Switch language** between Portuguese, English, and Spanish.

## In your hands

| | |
| --- | --- |
| Drag the body | Move |
| Blue tip | Rotate. Hold Shift to change the length too |
| Green **+** | Grow by 2 cm |
| Red button | Close |
| Mouse wheel | Rotate |
| Shift + wheel | Length |
| Ctrl + wheel | Scale |
| Right click | Center, horizontal, vertical, language |

`C` returns it to the center. `H` lays it flat. `V` stands it up. `Esc` closes it.

## Three languages

It opens in the system language. Portuguese, English, or Spanish: the menu, the title, and the hints follow. The line stays in English, because that is the name of the idea.

**Just another ruler, but better.**

## Where it runs

Windows, macOS, and Linux. A borderless window, always on top, on the desktop you are already using.

## Start

Python 3, with pip.

```bash
python -m pip install -r requirements.txt
python regua.py
```

Position, angle, length, and language are saved for the next time.
